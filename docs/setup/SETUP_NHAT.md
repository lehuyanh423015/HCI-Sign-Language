# Setup Nhat — Frontend/UI-UX

Required: Git, Node/npm theo repository và modern browser. Blender/MPFB không cần cho phát triển frontend thường ngày.

```cmd
node --version
npm --version
npm ci
npm run sync:data
npm run sync:technical-assets
npm run check
npm run dev
```

Mở `/technical-sign-preview`; kiểm tra GLB load, exact clip list, play/pause/replay, loop, speed, camera và warning. Không copy draft vào lesson catalog. Nếu lỗi gửi browser/version, console, route, asset URL, report và commit; không sửa generated `public` asset trực tiếp.
