# Ma trận môi trường nhóm

| Tool | Huy Anh | Mien | Nhat | Thao |
|---|---|---|---|---|
| Git | Required | Required | Required | Required |
| Blender 5.2.4 LTS | Required | Required | Not required | Not required by default |
| MPFB 2.0.18 | Required | Required | Not required | Not required |
| Node.js/npm theo `.nvmrc`/lockfile | Required for integration | Optional | Required | As needed for metadata validation |
| Modern browser | Required | Required for preview | Required | Required |

Chỉ môi trường phát triển hiện tại đã được kiểm tra. Mien, Nhat và Thao phải tự hoàn tất checklist trên máy của mình; tài liệu này không xác nhận máy của họ đã sẵn sàng.

- Huy Anh: canonical master, validators/export, S001–S003.
- Mien: isolated working copies, S004–S006; không sửa master.
- Nhat: React/TypeScript/Three.js và browser integration.
- Thao: reference, metadata, evidence, linguistic/QA gate; Blender không cần cho công việc thường ngày.
